# Lottery Insight v5.2.1 — News Accuracy Hotfix

เวอร์ชันนี้แก้ **เลขดังจากข่าวที่อ่านผิดเป็นวันที่/พ.ศ./ตัวเลขทั่ว ๆ ไป** โดยไม่เปลี่ยน Algorithm v3 (เลข 2 ตัว) หรือ v2 (เลข 6 หลัก) และยังคง Prize Checker, Logo/Favicon และหน้าสถิติเดิมไว้

## สิ่งที่แก้

- **อ่านเฉพาะเลข 2 ตัว/เลข 3 ตัวที่แหล่งข่าวระบุเป็นชุดชัดเจน** ไม่ scan ทุกเลขที่อยู่ใกล้คำว่า “หวย”
- รองรับรายการจากหัวข้อ เช่น `เลขท้าย 2 ตัว: 56, 52, 53` และ `เลขท้าย 3 ตัว: 562, 623, 563`
- รองรับ **ตาราง** ที่มีหัวคอลัมน์ `แหล่ง | เลขเด่น | เลข 2 ตัว | เลข 3 ตัว` และแยกแต่ละแหล่งเป็นคนละแถว แม้อยู่ในบทความเดียว
- เก็บเลขเด่นเป็นข้อมูลอ้างอิงต่างหาก **ไม่สร้างเลข 2/3 ตัวขึ้นจากเลขเด่นเอง**
- รองรับเลขนำหน้าด้วย 0 เช่น `01`, `04`, `081`, `007`
- ถ้าไม่มีชุดเลขตามหัวข้อที่ตรวจสอบได้ ระบบแสดงว่า **ยังไม่มีชุดเลขยืนยัน** แทนการเดา
- เก็บชื่อเจ้าของชุดเลข (`PickSource`) และแยกจากชื่อสำนักข่าว (`Source`); จำนวนแหล่งข่าวนับตามสำนักจริง ไม่แปลง “8 ชุดที่มาในข่าวเดียว” เป็น “8 สำนักข่าว”
- กรองข้อมูล v5.2 เก่าออกจากผลใหม่: เก็บแถว NewsArticles เก่าไว้ แต่ไม่แสดงหรือรวมคะแนน; เปลี่ยน NewsSnapshots ที่เป็น OPEN/CLOSED เดิมเป็น `LEGACY_UNVERIFIED` (ไม่ถูกนับใน Audit)
- แยกความล้มเหลวของข่าวจากระบบผลสลาก/ตรวจรางวัลเหมือนเดิม

## ใช้งานข่าวอัตโนมัติอย่างไร

ระบบยังเรียกข่าวจาก Google News RSS ได้โดยไม่ต้องมีคีย์ แต่ RSS บางรายการมีเพียงพาดหัว จึงอาจไม่มีชุดเลขที่ระบุชัดเจน **ถือว่าตั้งใจให้ว่าง ดีกว่าแสดงเลขผิด**

หากต้องการอ่านเนื้อหาบทความเต็มอัตโนมัติ มีทางเลือกดังนี้:

**A) GNews API + อนุญาตเว็บไซต์เฉพาะที่เข้าถึงได้ตามเงื่อนไขของเจ้าของเว็บไซต์**

Apps Script → Project Settings → Script Properties:

| Property | ตัวอย่าง | ความหมาย |
|---|---|---|
| `GNEWS_API_KEY` | `your_private_key` | ทางเลือก หากมี API Key (ไม่เก็บใน GitHub) |
| `NEWS_ARTICLE_HOSTS` | `example-news.com,www.example-news.com` | hostname ที่อนุญาตให้ Backend อ่านหน้า Article เพื่อแยกชุดเลขจริง (ไม่มี `https://`, ระบุ exact hostname) |

**B) RSS ของสำนักข่าวโดยตรง**

ตั้ง `NEWS_DIRECT_RSS_FEEDS` เป็น URL ของ RSS ที่คุณได้รับอนุญาตให้ใช้ คั่นด้วย comma หรือขึ้นบรรทัดใหม่ และใส่ hostname ของหน้า Article ใน `NEWS_ARTICLE_HOSTS` ด้วย ระบบจะนำข้อมูลจาก RSS ไปอ่านบทความเต็มภายใต้ขอบเขตที่กำหนด (สูงสุด 8 บทความต่อรอบข่าว)

> **ข้อสำคัญ:** อย่าเพิ่มโดเมนที่ไม่อนุญาตให้ดึงเนื้อหาอัตโนมัติ และอย่าใช้ URL redirect ของ Google News เป็น hostname ใน `NEWS_ARTICLE_HOSTS` เพราะไม่ใช่หน้า Article ต้นฉบับ ไม่เก็บหรือเผยแพร่เนื้อหาทั้งบทความ — เก็บเฉพาะชื่อเรื่อง ลิงก์ แหล่งข่าว ชุดเลขที่พบ และหลักฐานสั้น ๆ ภายใน Sheet

หากไม่ตั้งค่าทั้ง A หรือ B ระบบจะยังค้นจากหัวข้อ/คำอธิบาย RSS ที่ระบุเลขชัดเจนได้ แต่จำนวนข่าวที่แสดงจะน้อยกว่าเดิม ซึ่งเป็นผลจากการเพิ่มมาตรฐานความถูกต้อง ไม่ใช่ระบบเสีย

## อัปเกรดจาก v5.2

1. **สำรอง** Google Sheet และ `Code.gs` เดิมก่อน
2. เปิด Apps Script ของ Sheet → แทนด้วย `PRIVATE-backend/Code.gs` รุ่น v5.2.1
3. Run `setupSystem()` หนึ่งครั้งเพื่อเพิ่มคอลัมน์ K:O ใน `NewsArticles` และกักข้อมูลรุ่นเก่าที่ไม่ได้ยืนยัน
4. ตั้งค่า Script Properties สำหรับข่าวที่เลือก (หากต้องการให้ดึงจากเนื้อหาบทความเต็ม)
5. Run `syncLotteryNews()` หนึ่งครั้ง (ผลลัพธ์จะแสดง `verified` คือจำนวนชุดข่าวที่ผ่านเกณฑ์)
6. Run `syncLottery()` หนึ่งครั้งเพื่อตรวจว่าระบบผลสลากยังทำงานปกติ
7. **Deploy → Manage deployments → Edit → New version → Deploy**
8. อัปโหลดไฟล์ใน `github-pages-ready/` ทั้งหมดขึ้น GitHub Pages รวม `assets/` และตั้ง `DATA_URL` เดิมใน `config.js`
9. กด Ctrl + F5 และตรวจชีต `NewsArticles` คอลัมน์ `K:O` ว่ามี `PickSource / Evidence / ExtractionMethod / Confidence / FeaturedDigitsJson`

**ไม่ต้องลบ** `Results`, `Predictions`, `Predictions6` หรือ `NewsArticles` ด้วยตัวเอง

## Validation / ข้อจำกัด

- ทดสอบ parser กับ **ตารางตัวอย่าง 8 แหล่งของผู้ใช้** โดยตรง ทั้งช่องที่ว่าง/ไม่มี เลขนำหน้า 0 และรายการเสริม
- ทดสอบ migration, แยกข่าวซ้ำ, Snapshot, Audit, ความผิดพลาดของ provider รวม **25 tests ผ่าน** ในสภาพแวดล้อมจำลอง
- `Code.gs`, `script.js`, `config.js` syntax ผ่าน และตรวจหา Duplicate/Missing DOM IDs
- **ยังไม่ได้ทดสอบการดึงข่าวจริงจากบัญชี Google Apps Script และ hostname ของคุณ**; เว็บไซต์บางแห่งอาจบล็อก request, ใช้ JavaScript render เนื้อหา, หรือมีโครงสร้าง HTML เปลี่ยนแปลง ในกรณีนั้นระบบจะไม่เดาข้อมูลจากตัวเลขสุ่มในหน้าเว็บ
- ความนิยมในข่าวไม่ใช่หลักฐานว่าเลขนั้นมีโอกาสออกมากกว่าตัวอื่น และยังไม่ผสม News Score เข้ากับ Algorithm หลัก

## Troubleshooting

- **ขึ้น “ยังไม่มีชุดเลขยืนยัน”**: ตรวจ `NewsArticles`, `SystemLog`, ใช้ API/Direct RSS ที่มีเนื้อหาและตั้งค่า hostname อนุญาตตามสิทธิ; RSS title-only อาจไม่มีเลขที่ผ่านเงื่อนไข
- **ข่าวเดิมหายไปหลังอัปเกรด**: เป็นการกักข้อมูล v5.2 ที่เคยคัดผิด; ข้อมูลเก่ายังอยู่ใน Sheet สำหรับตรวจสอบ แต่ไม่นำมาคิดผล
- **News RSS error**: ตรวจ URL, สิทธิของ Apps Script และข้อจำกัดผู้ให้บริการ; ระบบตรวจสลากยังทำงานแยกต่างหาก
- **โลโก้/Favicon ไม่อัปเดต**: ตรวจว่ามี `assets/` ครบ และลอง hard refresh
